## Contact compliance

The public directory **does not** include telephone, email, or website (see profile copy).  
Prospects use **licensed business mailing addresses** and public profile/claim URLs only.  
Do not purchase lists or scrape non-public emails.

## 30-day working targets

| Metric | Target |
| --- | ---: |
| Owner contacts attempted | 100 |
| Legitimate listing claims | 10 |
| Organic search clicks (GSC) | 500 |

Validate the clicks target against the trailing 28-day GSC baseline before treating it as a floor vs stretch.

## Batch approval

Approve **batches** (this folder) rather than one-off messages. After approval, humans send/publish; the agent does not.
