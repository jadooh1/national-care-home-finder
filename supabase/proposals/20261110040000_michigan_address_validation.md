# Michigan address-field validation

The official LARA record key names column E "Facility Supplemental Address" and column F "Street Address". It also names a separate licensee address and a licensee supplemental address. The key does not say the facility supplemental field is a physical address, a mailing address, or a unit line. The public profile page uses one label, "Address:", and does not label that value physical or mailing.

The supplemental column is not copied into a blank street column.

## Counts

The file still has 4,480 rows. The official street column contains letter-and-digit text on 57 rows and is blank on 4,423 rows. Those 57 rows are the only rows with usable text in the official street column: AF 6, AS 17, AM 7, AL 19, AH 6, and XH 2. The two XH rows stay undescribed. All 234 XH/EXEMPT rows keep their original type code and receive no category name.

Publication-eligible records: 0. Michigan stays unpublished because the file still has no recorded export date, the supplemental field is not authoritatively defined, and the publication safeguards remain closed.

No supplemental value equals the street value. 904 supplemental values equal the separate licensee-address column. That overlap is recorded and is not treated as a mailing-address definition. Four street values equal the licensee address.

## Profile display

The completed license-identifier and one-per-type profile checks were not repeated. Address interpretation used the public profile for every row whose street column already had text, 57 rows, plus a small blank-street sample. On those 57 rows the displayed address contained both columns. The street column appeared first 56 times and the supplemental column appeared first once. That display does not rewrite either official column. Sampled blank-street profiles showed the supplemental text under "Address:" after ordinary spacing. That display is not a definition of the field.

Washington, Oregon, and California keep their current publication behavior. This page remains under `/development` and lists no facilities.
