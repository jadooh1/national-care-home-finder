# California directory architecture

California stays unpublished. This page is a development review of the validation counts. It does not list facilities, and it is not linked from the home page.

## Structurally eligible records

21,131 records passed the structural rule. That count is not a count of active homes or available placements.

Residential Care Facilities for the Elderly: 12,521. Licensed 7,939, closed 3,821, pending 738, on probation 23. The raw file date text is `5252025`.

Adult Residential Facilities: 8,610. Licensed 6,332, closed 1,840, pending 429, on probation 9. The raw file date text is `05252025`.

Neither raw file date is stored as an export date.

## Excluded records

1,889 records stay in the validation report with their original values: 1 blank category, 1,887 other license categories, and 1 shifted row.

## Disclosure and freshness

The facility-search welcome page and the CDSS licensing data page still point at `https://www.ccld.dss.ca.gov/carefacilitysearch/`. The data page also links to that host with `?rewrite=downloaddata`. Neither address was requested again after the application returned HTTP 503. No per-facility profile URL is recorded.
