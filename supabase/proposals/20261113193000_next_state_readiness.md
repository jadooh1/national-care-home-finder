# Next-state publication readiness

Washington remains the only public directory. This comparison uses the completed Oregon, California, Michigan, Pennsylvania, and North Carolina reviews. It does not publish a state, add a route, or adopt an export date.

## Mandatory and optional

A public roster row still needs an authoritative ISO export date, verified freshness, and a verified facility-specific disclosure link. A list-only directory does not require coordinates. `DIRECTORY_REQUIRES_COORDINATES` remains false. Georeferenced coordinates still cannot supply a map. Street text is mandatory only where the accepted directory contract requires it. Oregon's accepted contract already lists city and county and withholds street.
