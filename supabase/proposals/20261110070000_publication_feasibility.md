# Publication feasibility

Pennsylvania's 989-row validation stays unpublished. Its open-data object identifier is not a license number, the file has no per-row status, no disclosure prefix is verified, and the catalog timestamp is not an export date. Those four requirements stay closed. They are not investigated again here.

Washington, Oregon, California, Michigan, and Pennsylvania keep their current publication behavior. Wisconsin and Minnesota remain unselected. No additional state is implemented, and none is linked from the home page.

## North Carolina

The Division of Health Service Regulation publishes two workbooks from https://info.ncdhhs.gov/dhsr/reports.htm. The adult care home workbook has 566 unique license identifiers and 566 site addresses, all in North Carolina. Observed bed counts run from 9 to 201. The family care home workbook has 520 unique license identifiers and 520 site addresses, all in North Carolina. Observed bed counts run from 2 to 6. A separate facility-address column on the family care workbook includes addresses outside North Carolina, so that column is not copied into the site address.

The listings page labels both files updated 10/28/2026. Each workbook title says as of 10/2026. Those observations are not an ISO export date. Neither workbook has a per-row status column. The star-rating search posts by county, city, or facility name and has no license field, so no disclosure prefix is verified. Publication is not feasible.

## Iowa

The Department of Inspections, Appeals, and Licensing assisted-living dataset has 335 rows. Every certification identifier is unique, and every row has a facility address in Iowa. The identifier column is a certification number. Eighty-five ZIP values have five digits and 250 have nine. The file has no status column, no disclosure link, and no date column. A facility-location value is not a licensing coordinate. Publication is not feasible.
